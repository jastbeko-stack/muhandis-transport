# 🚌 خطوط المهندس | منصة النقل الجامعي في البصرة

منصة رقمية متكاملة لربط طلبة الجامعات في محافظة البصرة بسائقي خطوط النقل الجامعي المعتمدة، مع إمكانية التحديد الدقيق لموقع الانطلاق عبر الخريطة التفاعلية، والحجز المباشر عبر واتساب، ولوحة تحكم شاملة لإدارة الخطوط والطلبات.

---

## 🌟 الميزات الرئيسية

1. **تصفح وحجز الخطوط الجامعية**:
   - أكثر من 16 خطاً معتمداً تغطي جامعات البصرة (كرمة علي، باب الزبير، المعقل، النفط والغاز، التقنية الجنوبية).
   - بطاقات تفاعلية تعرض تفاصيل السائق، نوع وموديل المركبة، السعة، المقاعد المتاحة، السعر الشهري، ومواعيد الذهاب والعودة.
   - فلترة مخصصة لخطوط **بنات فقط** و **مختلط**، والدوام (صباحي / مسائي).

2. **خريطة تفاعلية وحجز دقيق (Leaflet)**:
   - تحديد نقطة الانطلاق ومكان السكن عبر سحب الدبوس على الخريطة أو زر تحديد الموقع الجغرافي (GPS).
   - رسم خط المسار بين موقع الطالب والجامعة.
   - توليد رسالة واتساب منسقة تلقائياً متضمنة كافة تفاصيل الخط ورابط الموقع الجغرافي على Google Maps.

3. **تسجيل السائقين وإضافة خط جديد**:
   - نموذج إضافة خط للسائقين مع إمكانية طلب الترقية إلى **خط مميز VIP**.
   - مراجعة إدارية مسبقة للخطوط قبل نشرها للطلبة.

4. **طلب تغطية للمناطق غير المخدومة**:
   - للطلبة الذين لا يجدون خطاً يغطي مناطقهم، يمكنهم إرسال طلب تغطية مع تحديد موقعهم على الخريطة لتنسيق خط جديد مع السائقين.

5. **لوحة تحكم إدارية متقدمة (Admin Dashboard)**:
   - محمية برمز سري: `ht8k`.
   - إدارة الطلبات قيد المراجعة: اعتماد الخطوط كعادي أو ترقيتها إلى VIP، أو رفضها.
   - إدارة الخطوط النشطة: تبديل شارة VIP أو حذف الخط.
   - مراجعة طلبات التغطية مع روابط الخريطة والتواصل المباشر مع الطالب عبر واتساب.
   - إمكانية إعادة تعيين البيانات التجريبية بضغطة زر.

6. **تصميم احترافي وهوية بصرية بصراوية**:
   - دعم كامل للغة العربية والاتجاه من اليمين لليسار (`dir="rtl"`).
   - وضع ليلي / نهاري (Dark / Light Mode) متكامل ومتناسق ومحفوظ محلياً.
   - خطوط عربية حديثة: **Cairo** و **Tajawal**.
   - ألوان الهوية: الكحلي البصراوي (`#12295E`) والذهبي (`#F2B233`).

## 🚀 تشغيل المشروع محلياً

```bash
# تثبيت الحزم (إن لم تكن مثبتة مسبقاً)
npm install

# تشغيل خادم التطوير
npm run dev

# بناء المشروع للإنتاج
npm run build

# معاينة البناء
npm run preview
```
